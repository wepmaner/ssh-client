# План: файловый менеджер по SFTP

Спека: `docs/superpowers/specs/2026-11-15-file-manager-design.md`. Ветка `files` от `main` @ 9f5e283.

## Задача 1 — слой SFTP (`internal/sshclient/remotefs.go`, `localname.go`)
- `List`, `Mkdir`, `RenameNoReplace`, `RemoveAll` (с колбэком прогресса и ctx), `Walk` для плана передачи (размеры, папки, ссылки по правилам спеки).
- Копирование файла сервер↔компьютер во временное `.part` с докачкой по смещению, перенос mtime, переименование на место (`replace`/`skip`).
- `SafeLocalName` и проверка, что путь остаётся в папке назначения.
- Тесты на in-process sftp (`sshtest` с `SFTPRoot`): докачка после обрыва, отмена не оставляет файла под настоящим именем, имена Windows, ссылки-циклы.

## Задача 2 — вкладки и задачи (`app/files.go`, `app/files_jobs.go`, `app/files_api.go`)
- `filesTab` — пользователь `hostConn`, вход через свой `outStream`/`inputQueue` (`files:login:<id>`), кэш `*sftp.Client`.
- Очередь задач вкладки (по одной), события, троттлинг, переподключение с паузами, докачка, итог с ошибками.
- `hostConn.dropLocked`: секреты сохраняются при пользователях-файлах.
- Закрытие вкладок в `ServiceShutdown` и `VaultRestore`; удаление хоста отменяет их.
- `FilesPick*`, `FilesShowLocal`, `files:drop` из `WindowFilesDropped`; `EnableFileDrop` и `SSHCLIENT_INSTANCE` в `main.go`.
- Тесты в стиле `mcp_conn_test.go`/`sessions_test.go`; `wails3 generate bindings -clean=true -ts`.

## Задача 3 — интерфейс (`frontend/src/lib/files/`)
- Вкладки файлов в `sessions` (поле `kind`), заголовок, Ctrl+Tab, закрытие с подтверждением при передачах.
- `FilesView`: панель, крошки/ввод пути, поиск, список с колонками, выделение, клавиши, меню, переименование/новая папка в строке, перетаскивание внутрь (из Проводника и между строками), очередь передач, диалоги конфликта и удаления, карточки входа и ошибки.
- Пункт «Файлы» в меню хоста, кнопка «Файлы» у консоли.
- Тесты vitest как у соседних компонентов, `svelte-check`, `native.test.ts`.

## Задача 4 — интеграция и живая проверка (оркестратор)
- Своя копия рядом с рабочей (`APPDATA` в scratchpad, `SSHCLIENT_INSTANCE`), тестовый sshd в Docker `127.0.0.1:2222`.
- Сценарии: вход по паролю, навигация, загрузка нескольких файлов перетаскиванием, папки туда и обратно, обрыв связи посреди передачи (`docker pause`/`restart`), переименование, удаление, конфликты, кириллица, закрытая папка.
- Ревью ветки, исправления, CLAUDE.md, коммиты.
