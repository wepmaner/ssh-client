# Файловый менеджер по SFTP — проект

Дата: 2026-11-15. Владелец поставил задачу и ушёл, решения приняты исполнителем (помечены «решение исполнителя»).

## Зачем

Владелец хочет смотреть папки сервера как в Проводнике, перекидывать туда файлы с компьютера (в том числе перетаскиванием), забирать с сервера сразу несколько файлов и папок, переименовывать и удалять, и чтобы обрыв связи не терял работу. Только SSH (SFTP-подсистема поверх того же подключения), FTP не поддерживаем.

## Цели

- Вкладка «Файлы» хоста в заголовке окна рядом с консолями: навигация, список с колонками, выделение, клавиатура, контекстное меню, перетаскивание.
- Загрузка файлов и папок с компьютера (кнопка, системный диалог, перетаскивание из Проводника на список или на папку в списке).
- Скачивание нескольких файлов и папок разом в выбранную папку компьютера.
- Новая папка, переименование, перемещение перетаскиванием внутри сервера, удаление (с подтверждением, рекурсивно).
- Очередь передач во вкладке: прогресс, скорость, отмена, повтор; при обрыве связи передача ждёт и продолжает с места обрыва.
- Конфликты имён: «Заменить / Пропустить / Отмена» на всю операцию.

## Не цели (v1 файлового менеджера)

- Перетаскивание с сервера в Проводник (нужен OLE DoDragDrop с отложенными данными; WebView2/Wails этого не дают) — вместо него «Скачать в…».
- Редактирование файла с обратной синхронизацией, «открыть» файл в программе Windows.
- Права (chmod), владельцы, копирование внутри сервера, две панели.

## Анти-цели

- Полузаписанный файл под настоящим именем (на сервере или на компьютере) после обрыва или отмены.
- Запись за пределы выбранной папки компьютера из-за имени с сервера (`..`, `\`, `C:`), падение на именах, недопустимых в Windows.
- Спиннеры на локальных действиях, «веб-страница» вместо нативного вида, системный `<select>`.
- Пароль или фраза на диске, в событиях, журнале.

## Подход

Рассмотрены: (1) отдельное окно файлового менеджера; (2) раздел боковой панели «Файлы» с выбором хоста; (3) вкладка хоста в заголовке окна, как консоль. Выбран (3) (решение исполнителя): как в Windows Terminal/WinSCP — несколько хостов открыты параллельно, переключение Ctrl+Tab, вход тем же путём, что у консоли. Окно (1) ломает «одно окно, свои вкладки», раздел (2) не даёт держать два хоста.

Вкладка — ещё один пользователь общего подключения хоста (`hostConn`) наряду с консолями, пробросами и MCP. Передачи — тоже пользователи, пока идут.

## Поведение

### Вход и подключение
- Открытие: меню хоста (правый щелчок / «Ещё») → «Файлы»; в консоли — кнопка «Файлы» в заголовке рядом с поиском (открывает файлы того же хоста или переключает на уже открытую вкладку файлов этого хоста).
- Пока нет подключения, вкладка показывает карточку «Вход на <хост>» с мини-терминалом (`forwards/MiniTerminal.svelte` с `write`/`attach`), где сервер спрашивает фразу/пароль; окно доверия ключа сервера — общее. Если подключение хоста уже живо (открыта консоль), вход не нужен.
- Ошибка входа — карточка с текстом по-русски, подробностями и «Повторить».
- **Секреты при обрыве (решение исполнителя, расширяет решение 2026-10-27):** пока у подключения есть пользователи-файлы (вкладка файлов или идущая передача), принятые фраза и пароль не стираются при обрыве связи, чтобы передача продолжилась сама. Стираются по-прежнему, когда ушёл последний пользователь, при правке параметров входа, удалении хоста и выходе. Если сервер секрет отверг — вкладка снова показывает вход.

### Навигация и список
- Старт в домашней папке (`RealPath(".")`).
- Панель: Назад, Вперёд, Вверх, Обновить; строка пути из «крошек» (щелчок по крошке — переход; щелчок по пустому месту строки или Ctrl+L — поле ввода пути, Enter — перейти, Esc — отмена); поиск по имени в текущей папке (Ctrl+F, мгновенный); кнопки «Загрузить» (меню: «Файлы…», «Папку…»), «Новая папка», «Скачать» (активна при выделении); переключатель скрытых файлов (имена с точки, по умолчанию скрыты, выбор помнится в рамках вкладки).
- Колонки: Имя, Изменён, Размер, Права (`drwxr-xr-x`). Сортировка щелчком по заголовку, папки всегда первыми. Ссылки показаны значком-стрелкой; ссылка на папку открывается как папка; битая ссылка — приглушена.
- Выделение: щелчок, Ctrl+щелчок, Shift+щелчок, Ctrl+A, стрелки, Home/End, Shift+стрелки. Двойной щелчок/Enter по папке — войти; по файлу — «Скачать…».
- Клавиши: Backspace и Alt+↑ — вверх, Alt+←/→ — назад/вперёд, F5 — обновить, F2 — переименовать, Del — удалить, Ctrl+Shift+N — новая папка, Ctrl+Shift+C — копировать путь.
- Правый щелчок по элементу (выделяет его, если он не в выделении): Открыть (папка), Скачать…, Переименовать (один), Копировать путь, Удалить. По пустому месту: Загрузить файлы…, Загрузить папку…, Новая папка, Обновить, Копировать путь папки, Показать/Скрыть скрытые.
- Строка состояния списка: «N объектов», при выделении «выбрано M · размер файлов».
- Пустая папка: «Папка пуста. Перетащите сюда файлы с компьютера».
- Нет доступа / папка не найдена: сообщение в области списка, путь остаётся, можно уйти назад/вверх.

### Изменения
- Новая папка: строка в списке с полем «Новая папка», Enter — создать, Esc — отмена; имя занято — ошибка рядом с полем.
- Переименование: поле в строке (имя без расширения выделено), Enter/Esc; без перезаписи существующего.
- Перемещение: перетаскивание выделенных строк на папку списка или на крошку пути; без перезаписи (имя занято — ошибка в подсказке, остальные перемещены).
- Удаление: диалог «Удалить N объектов? Папки удаляются со всем содержимым. Это нельзя отменить.» → задача удаления в очереди (может быть долгой).

### Передачи
- Загрузка: «Загрузить → Файлы…/Папку…» (системный диалог, несколько файлов) или перетаскивание из Проводника на список (в текущую папку) или на строку папки (в неё). Цель подсвечивается.
- Скачивание: «Скачать…» → системный выбор папки (по умолчанию последняя выбранная за запуск, иначе «Загрузки»). По завершении у задачи кнопка «Показать в папке» (Проводник с выделением).
- Перед запуском проверка конфликтов верхнего уровня: если в цели уже есть такие имена — диалог «В папке уже есть: a.txt, b … (и ещё N)» → Заменить / Пропустить / Отмена. Папка с тем же именем сливается, файлы внутри неё следуют тому же выбору.
- Каждый файл пишется во временное имя рядом с целью (`<имя>.sshclient-<id>.part`) и переименовывается на место в конце; время изменения переносится.
- Очередь внизу вкладки появляется при первой задаче: строка-сводка («Передаётся 2 из 5 · 12,3 из 40 МБ · 3,2 МБ/с», развернуть/свернуть) и строки задач: направление, заголовок, полоса прогресса, состояние, действия (Отмена, Повторить, Показать в папке, Убрать). «Очистить завершённые». Задачи одной вкладки выполняются по одной (решение исполнителя: так проще понимать прогресс и не упираться в MaxSessions).
- Обрыв связи: задача переходит в «Связь прервана, повтор через N с» и сама переподключается (паузы 1, 2, 5, 10, 30 с, дальше по 30 с, до 10 минут), затем продолжает текущий файл с места обрыва (докачка по размеру временного файла). Через 10 минут — «Ошибка» с «Повторить», временный файл сохраняется для докачки при повторе; при «Отмене» и закрытии вкладки временные файлы удаляются. У ждущей задачи есть «Повторить сейчас»: пауза обрывается, переподключение сразу.
- Обрыв связи замечает и сама вкладка (следит за клиентом, на котором открыта её SFTP-сессия): показывает плашку «Связь с сервером прервана. Переподключение…» и переподключается в фоне с теми же паузами, пока открыта; ошибки, которые не пройдут сами (ключ сервера изменился, сервер не подтверждён, хост удалён, вкладка закрыта, параметры входа изменились, сервер отверг секрет), останавливают попытки и показывают ошибку с «Повторить».
- Ошибка одного файла (нет прав, недопустимое имя) не останавливает задачу: файл пропускается, в конце «Готово, с ошибками: N» и список в подробностях.
- Имена с сервера, недопустимые в Windows (`<>:"/\|?*`, управляющие, CON/PRN/AUX/NUL/COM1–9/LPT1–9, точка или пробел в конце), при скачивании меняются: недопустимые символы → `_`, зарезервированное имя → `_CON`; число переименованных показывается в итоге. Путь назначения всегда проверяется: остаётся внутри выбранной папки.
- Ссылки при скачивании и загрузке: выбранная пользователем ссылка следует цели; внутри рекурсии ссылки на папки пропускаются (защита от циклов), ссылки на файлы копируются как файлы.
- Вкладка в заголовке во время передачи показывает процент. Закрытие вкладки с идущими задачами спрашивает «Остановить передачи и закрыть?».

## Контракт бэкенда (Go, `app/files*.go`)

Все методы — методы `App`, ошибки по-русски.

```
FilesOpen(hostID string) (string, error)              // id вкладки; вход начинается сразу
FilesLoginAttach(tabID string) error                  // мини-терминал подписался на files:login:<id>
FilesLoginWrite(tabID, dataB64 string) error          // ввод в мини-терминал входа
FilesRetry(tabID string) error                        // новый вход после ошибки
FilesClose(tabID string) error                        // отмена задач, удаление .part, уход с подключения
FilesHome(tabID string) (string, error)
FilesList(tabID, dir string) (FilesListDTO, error)
FilesMkdir(tabID, dir, name string) (string, error)   // путь новой папки
FilesRename(tabID, from, newName string) (string, error) // новое имя в той же папке
FilesMove(tabID string, paths []string, destDir string) error
FilesDelete(tabID string, paths []string) (string, error)   // id задачи
FilesConflicts(tabID, direction string, sources []string, dest string) ([]FilesConflictDTO, error) // "upload"|"download"; имена верхнего уровня
FilesUpload(tabID string, local []string, remoteDir, onConflict string) (string, error)   // onConflict "replace"|"skip"
FilesDownload(tabID string, remote []string, localDir, onConflict string) (string, error)
FilesJobCancel(tabID, jobID string) error
FilesJobRetry(tabID, jobID string) error
FilesJobRemove(tabID, jobID string) error             // только завершённую
FilesJobs(tabID string) ([]FilesJobDTO, error)
FilesPickUpload(folder bool) ([]string, error)        // системный диалог; [] при отмене
FilesPickDownloadDir() (string, error)                // "" при отмене; запоминает выбор
FilesShowLocal(path string) error                     // Проводник с выделением
```

DTO:
```
FilesStateDTO   { state: "connecting"|"connected"|"error"|"closed", message, detail string, retryable bool }
FilesListDTO    { path string, entries []FilesEntryDTO }
FilesEntryDTO   { name string, dir bool, link bool, broken bool, size int64, mtime int64 /*unix ms*/, mode string }
FilesJobDTO     { id, kind /*upload|download|delete*/, title, state /*queued|running|waiting|done|failed|cancelled*/,
                  message, detail string, total_bytes, done_bytes int64, total_files, done_files, failed, renamed, skipped int,
                  current string, speed_bps int64, dest string, retry_in_s int }
FilesConflictDTO { name string, merge bool /*обе стороны — папки: сливаются; только тогда диалог говорит о слиянии*/ }
FilesDropDTO    { tab string, dir string, paths []string }
```

События: `files:state:<tab>` (FilesStateDTO), `files:login:<tab>` (base64-вывод мини-терминала, держится до FilesLoginAttach), `files:job:<tab>` (FilesJobDTO, не чаще 5 раз в секунду на задачу, плюс каждое изменение состояния), `files:changed:<tab>` (`{dir}` — папка изменилась из-за задачи), `files:drop` (FilesDropDTO). Перетаскивание из Проводника: окно с `EnableFileDrop: true`; элемент-цель имеет `data-file-drop-target`, `data-files-tab`, `data-files-dir`; Go ловит `events.Common.WindowFilesDropped` и шлёт `files:drop`.

Слой SFTP — `internal/sshclient/remotefs.go` (+ `localname.go`): операции над `*sftp.Client` (список, mkdir, rename без перезаписи, рекурсивное удаление, обход дерева) и копирование файла с докачкой и `ctx`. Вкладка держит один `*sftp.Client` на живом `*ssh.Client` и открывает новый после переподключения; задача — свой.

## Изменения вокруг

- `hostConn.dropLocked`: не стирать секреты, если среди пользователей есть файлы (`*filesTab`, `*filesJob`).
- Восстановление из копии и выход закрывают вкладки файлов как консоли.
- `main.go`: `EnableFileDrop: true` в окне. Для живых проверок рядом с рабочей копией: в сборке `version == "dev"` переменная `SSHCLIENT_INSTANCE` добавляется к `UniqueID` одной копии (данные разводятся своей `APPDATA`).
- CLAUDE.md: правило о файловом менеджере и о секретах при обрыве.

## Оставлено исполнителю

Иконки (свои SVG в стиле существующих), точные отступы, формат размеров/дат (как в Проводнике: «12,3 МБ», «15.11.2026 14:05»), тексты подсказок.
